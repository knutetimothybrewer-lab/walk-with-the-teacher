# Class Tickets (web pages only)

This folder is the part of the warm-up / exit-ticket system that students and the teacher open in a browser.

* `site/index.html` is the student page (class code + student ID).
* `site/teacher.html` is the teacher page (passcode).
* `site/config.js` holds the web-app address (`API_URL`) that connects the pages to the teacher's Google Sheet.

The pages contain no questions and no answers. Everything is fetched from, and graded in, the teacher's own Google Apps Script,
so there is nothing here that gives answers away. Lesson plans, the item bank, and the backend source are kept in a private repository.
