# Life Decisions: The Health & Relationships Investigation

Unit 8 (Family Life & Sexuality) summative assessment for Grade 10 Health. An auto-graded, interactive, about-an-hour investigation in six chapters (40 questions, 100 points, 90-minute server-enforced limit, three attempts per question scoring 100/85/75/0). A static front end (GitHub Pages) talks to a Google Apps Script web app bound to your grade Sheet. Students never receive an answer key.

> **Status: provisional.** The Unit 8 slides were not available when this was built, no health fact could be checked against an outside source, and the Google back end has never run on Google (only in a strict simulator). Read `docs/TEACHER_REVIEW.md` before using it with students.

## Try it now (no setup)

Open `index.html` through any static server (for example `node tools/dev-server.js`, which serves the practice set). With `API_URL` empty in `js/config.js` the page runs **demo mode**: a labeled nine-question practice set and its own pretend server. Nothing is recorded. Demo codes and the demo teacher password are shown on the sign-in screen.

## Put it in front of students

Follow `docs/SETUP.md` (about 30 minutes): create the Sheet, paste `apps-script/Code.gs`, run the **Unit 8** menu steps, load the question bank (a private file delivered separately), deploy the web app, paste its URL into `js/config.js`, publish, and run **Test Connection**.

Teacher Mode: type `WALK-TEACHER` in the class-code box at sign-in, then the teacher password. It has Preview (with an answer-key overlay), Monitor, Reset student, Settings, Analytics and Reference.

## Layout

```
index.html, css/, js/          the student and teacher front end (vanilla ES modules, strict CSP)
server/core.js                 grading, sessions, timer, teacher logic (one file, runs in Node, the browser demo and Apps Script)
server/gas/                    Google Sheets adapter and workbook tools
apps-script/Code.gs            GENERATED from server/: paste this into Apps Script (tools/build-apps-script.js)
content/items.json             public question text (no answers); alignment.json, sources.json, figures.js
content/demo/                  the public practice set
assets/                        three SVG figures (flagged for your approval)
authoring/  private/           NOT in git: question source with answers; generated key files
vault/                         encrypted backup of authoring/ (needs your passphrase)
tools/                         build, vault, secrets gate, dev server, doc generator
tests/                         unit, Apps Script simulator, end-to-end, performance, mutation
```

## Commands

```
node tools/build-content.js     lint and build the content (needs authoring/; restore it with the vault)
node tools/build-apps-script.js rebuild apps-script/Code.gs
node tools/gen-docs.js          regenerate the generated docs
npm test                        unit + Apps Script simulator tests (Node 20+, no install needed)
npm install && node tests/e2e/run.js     end-to-end tests (needs Playwright's Chromium)
node tests/mutation/run.js      mutation testing of the server code
node tools/check-secrets.js     run before every commit
```

Restoring the private source on a new machine: `W8_VAULT_PASS="..." node tools/vault.js unlock`.

## Known limitations (the short list)

Curriculum unverified; health facts unverified against sources; live Apps Script deployment untested; times, difficulty and reading level unmeasured with students; identity is class code plus ID plus last name, not proven; question wording is readable before the test; the earlier commits on the feature branch contain text that gave away two labeling answers (see `docs/SECURITY.md`); screen-reader and real-device testing not done. Details in `docs/TESTING.md` and `docs/SECURITY.md`.
