Teacher setup helper

Make your teacher codes

Type a code, press the button, and copy the line it prints into js/config.js. Nothing you type here is sent anywhere; it is turned into a one-way code (hash) in your browser.


    

    
Class codes
Class codes are typed in plain text in js/config.js (classCodes: ['UNIT7']) and in the SETTINGS tab of your Google Sheet. They are not secret from students (you tell them the code); the code only keeps outsiders out.

    
The dashboard passcode for your Google Sheet is NOT set here. It is created by setupGradebook() and changed from the sheet's "Unit 7 Gradebook" menu.
