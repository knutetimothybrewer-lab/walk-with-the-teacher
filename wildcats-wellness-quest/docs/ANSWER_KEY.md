# Answer key, compatibility matrices and rationales

> **Teacher-only reference. Generated by `node tools/gen-docs.js` from the live content, so it always matches what the app scores.** Client-side keys are inspectable by a technically capable student; see README "Honest technical limits."

## How scoring works

- 100 automatically scored points, 0 teacher-graded points, no external grading.
- `earned = rubric fraction x item points x attempt cap` (cap 100% / 90% / 75% for attempts 1 / 2 / 3). The best earned value across permitted attempts is kept; only the final total is rounded.
- Credit is per option (0 to 1). **Multi-select** parts: credit = sum of chosen options' credit / best possible sum. **Compatibility (dependent) parts**: the credit of an option depends on the student's earlier selection (matrix below). `depCap`: if the anchor part earned 0, dependent parts are multiplied by that factor.
- Variants are equivalent transfer versions with the same part structure and point maximum; attempt 1 uses variant A, attempt 2 variant B, attempt 3 variant C (short items have two variants).
