Keyboard shortcuts

  • ← / → previous / next stop
  • ? open this list
  • Esc close this list
  • Tab / Shift+Tab move between controls
  • Enter or Space press a button or switch
  • Sliders: ← → adjust (arrow keys then change the value, not the stop)

Every stop can be revisited. Your work in a stop is kept while this tab is open.
