# DEED & DEBT: Concept Map

Each game mechanic and the concept it teaches, aligned to:

- **CEE**: Council for Economic Education, *Voluntary National Content Standards in Economics* (2nd ed.). The 20 standards are listed at the end.
- **NSPFE**: CEE and Jump$tart, *National Standards for Personal Financial Education* (2021): Earning Income (EI), Spending (SP), Saving (SV), Investing (IN), Managing Credit (MC), Managing Risk (MR).

"Where" tells you where students meet it in the game.

## Core board mechanics

| Mechanic | Where | Concept taught | Key vocabulary | CEE | NSPFE |
|---|---|---|---|---|---|
| Buy a lot or send it to auction | Landing on an unowned lot | Choices have costs; buying uses cash that could earn elsewhere | opportunity cost, price discovery | 1, 2, 7 | SP, IN |
| 30-second auction starting at 50% of price | After a player passes | Markets set prices through competing bids | auction, price discovery | 7, 8 | SP |
| Rent; a full color group doubles base rent | Landing on an owned lot | Income from property; market power | rent, income, monopoly | 9, 13 | EI, IN |
| Build houses evenly, then a hotel | Property menu | Investment raises future income; capital improvements | investment, return | 2, 15 | IN |
| Board mortgage at 50%, buy back at +10% | Property menu, debt screen | Borrowing against assets, the cost of credit, collateral | collateral, mortgage, liquidity | 12 | MC |
| Trades with estimated value for each side | Trade button | Voluntary exchange makes both sides better off when each values what the other has | voluntary exchange, value | 5 | SP |
| Soft turn timer, Year timer | Throughout | (classroom pacing) | | | |

## Learning supports

| Feature | Purpose |
|---|---|
| **Econ Insight** + **Vocab** on every card | Links each event to the concept, with a tappable term |
| **Real world:** footnotes | Flags every simplification so the game teaches nothing false |
| **Why?** on every decision | Explains the tradeoff in plain language before students commit |
| Glossary drawer (45+ terms), first-use underlines, 🔊 read-aloud | Vocabulary support and reading access |
| Quick Checks (optional) | One-question checks for understanding, keyed to the space |
| Pre/post check (5 questions) | Opportunity cost, compound interest, credit, property tax, real value |
| Results page reflection prompts | Generated from each student's own game ("Your debt doubled in Year 5. What caused it?") |
| Teacher Debrief Guide | Discussion questions keyed to the events, votes and outcomes of that game |
